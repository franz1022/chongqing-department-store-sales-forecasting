# Data Directory

The raw and processed datasets are intentionally excluded from this repository.

This project is a forecasting methodology and portfolio demonstration. It does not claim to use confidential internal data from a real Chongqing retailer. The dataset is treated as a structured educational, synthetic, or adapted retail dataset.

## Required Raw Files

Place the following files in:

```text
data/raw/
```

Required files:

```text
sales.csv
features.csv
stores.csv
```

## Expected Structure

### sales.csv

Required key columns:

- `store_id`
- `department`
- `date`
- `weekly_sales`
- `is_holiday`

Expected granularity:

```text
one row per store + department + week
```

### features.csv

Required key columns:

- `store_id`
- `date`

Example feature columns:

- temperature
- fuel price
- markdown variables
- CPI
- unemployment
- holiday information

Expected granularity:

```text
one row per store + week
```

### stores.csv

Required key column:

- `store_id`

Example store attributes:

- store type
- store size
- region

Expected granularity:

```text
one row per store
```

## Generated Data

Processed datasets are generated by:

```powershell
python .\src\01_data_cleaning.py
```

Generated files are stored under:

```text
data/processed/
```

Both `data/raw/` and `data/processed/` are excluded through `.gitignore`.

## Reproducibility Note

To reproduce the full pipeline, prepare source tables with the expected schema and then follow the execution order documented in the main README.
